How it works

Two simple steps, then every tool is ready

Prepare the marks sheet once. Every report, card and list below is made from it.

1

Get the Marks Entry Sheet

Give the UDISE+ student list — we fill in every child’s name for you.

Download Marks Entry Sheet ముందు పైన UDISE+ లిస్ట్ ఇవ్వండి. పిల్లల పేర్లతో షీట్ తనంతట అదే డౌన్లోడ్ అవుతుంది.

One file for every class, with a tab for each class. Type marks in the yellow cells — grades, totals, results and ranks fill in by themselves. Open it in Excel or Google Sheets.

2

Upload the filled Marks Sheet

Upload once. Every tool below uses this sheet.

or

For a Google Sheet, tap Share and set “Anyone with the link” to Viewer, then copy the link.

Step 3 · Generate

Choose a tool

Each tool reads the marks sheet you uploaded. Pick a class and open — the rest is done for you.

  1. Tool 01

    Student Report Cards

    Report cards for every student from the uploaded marks.

    First choose తెలుగు or English, then download or open.
  2. Tool 02

    Digital Progress Cards

    A personal link for each student’s card, with audio, to send to parents on WhatsApp. Select students to download their cards.

    First choose తెలుగు or English, then open the parent links.
  3. Tool 03

    Rank Lists

    Class rank list for any exam, spread evenly over A4 pages to display in the classroom.

  4. Tool 04

    Grading Abstract

    Subject-wise grade counts for boys, girls and total, with pass percentage, on one A4 page.

  5. Tool 05

    Subject Analysis

    All exams of one subject in one class, with a two-page PDF.

  6. Tool 06

    Substitute Teacher Time Table

    Upload the time table once, mark absent teachers, and download the substitute time table as a PDF.

    Use it every morning as the Extra Work app
  7. Tool 07

    Time Table Generator

    Build the full school time table automatically.
