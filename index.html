  1. Tool 01 · Report cards రిపోర్ట్ కార్డులు

    • Save links as Excel
    Card language
    First choose తెలుగు or English, then open the parent links.
  3. Tool 03 · For the class teacher తరగతి డాష్‌బోర్డ్

    • Pass %, grade spread, trend

    • Day-by-day study plan
    • Science Lab links
  4. Tool 04 · Classroom ర్యాంక్ జాబితా

    Subject-wise grade counts for boys, girls and total, with pass percentage, on one A4 page.

    • Pass % per subject
    • Landscape A4
  6. Tool 06 · Insights విషయ విశ్లేషణ

    Subject Analysis

    All exams of one subject in one class, with a two-page PDF.

    • Who moved up or slipped
    • Toppers & needs support
    • Teacher action plan
    • 2-page PDF

    • Saved on this device
    • Fair, rule-based choice

    Use it every morning as the Extra Work app
